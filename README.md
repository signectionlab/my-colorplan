## 📌 1. 프로젝트 소개

**My Color Plan(컬러플랜)**은 색채 비전공자, 소상공인, 예비 창업자 등 컬러 활용 능력을 높이고 싶은 성인을 위한 인터랙티브 색채 교육콘텐츠입니다.

색의 이름과 톤을 알아보는 데서 그치지 않고, 사용자가 직접 색을 **선택 → 관찰 → 비교 → 배색 → 적용 → 정리**하는 학습 경험을 제공합니다.

선택한 색과 기록은 다음 단계로 이어지고, 마지막에는 활용 가능한 **컬러디자인 계획 초안**으로 정리됩니다.

| 항목 | 내용 |
| --- | --- |
| 🎯 개발 목적 | 초보자의 색채 이해와 실제 컬러 활용을 연결하는 체험형 학습 |
| 👥 교육 대상 | 일반 성인, 소상공인, 예비 창업자, 컬러디자인 입문자 |
| 🧩 학습 방식 | 자기주도형 6단계 실습 |
| 📚 주요 학습 분야 | 색채 이해, 색채 대비, 컬러코디네이션, 컬러브랜딩 |
| 📄 최종 결과물 | 브랜드 컬러 계획서 초안 및 PDF |
| 🚀 개발 단계 | MVP 구현 및 배포 완료 |

## 💡 2. 개발 배경 및 목적

색채는 브랜드의 이미지와 인상을 형성하는 중요한 시각적 요소입니다.

그러나 색채를 처음 접하는 학습자는 다음과 같은 어려움을 경험할 수 있습니다.

- 원하는 이미지를 구체적인 색으로 표현하기 어렵습니다.
- 색의 이름과 특성을 배워도 실제 색 조합에 활용하기 어렵습니다.
- 여러 색의 역할과 적절한 사용 비율을 정하기 어렵습니다.
- 선택한 색을 매장, 상품, 온라인 콘텐츠 등에 어떻게 적용해야 할지 판단하기 어렵습니다.
- 자신이 선택한 색과 배색의 이유를 다른 사람에게 설명하기 어렵습니다.

컬러플랜은 이러한 어려움을 **짧은 설명 + 직접 조작 + 즉각적인 시각적 확인**으로 풀어가는 교육용 도구입니다.

학습자는 단순히 색채 지식을 읽고 암기하는 것이 아니라, 색을 직접 선택하고 비교하고 수정하며 자신의 컬러디자인 방향을 찾아갑니다.

특정 색채 조합의 정답을 자동으로 판단하기보다 학습자가 자신의 목적에 맞는 컬러를 선택하도록 지원합니다.

## 🎓 3. 교육 대상 및 학습 목표

### 👥 교육 대상

- 색채와 컬러디자인을 처음 배우는 성인
- 자신의 브랜드를 기획하는 예비 창업자
- 매장과 상품의 컬러브랜딩을 고민하는 소상공인
- 디자인 전문 도구 없이 컬러 계획을 수립하고 싶은 학습자
- 색채를 활용한 비즈니스 및 콘텐츠 제작에 관심 있는 학습자

### 🎯 학습 목표

본 교육콘텐츠를 경험한 학습자는 다음 활동을 수행할 수 있습니다.

1. 색의 이름과 기본적인 특성을 이해하고 구분할 수 있습니다.
2. 색의 밝기와 톤에 따른 이미지 변화를 비교할 수 있습니다.
3. 배경·글자·도형의 색을 바꾸며 대비 효과를 관찰할 수 있습니다.
4. 주조색·보조색·강조색의 역할을 이해하고 사용 비율을 조절할 수 있습니다.
5. 선택한 컬러를 실제 활용 예시에 적용하고 적합성을 검토할 수 있습니다.
6. 자신의 색채 선택 결과를 브랜드 컬러 계획서로 정리할 수 있습니다.

> 색의 상징과 이미지에 대한 심화 학습은 향후 확장할 콘텐츠입니다. 현재 MVP의 핵심은 색채 탐색·비교·배색·적용 실습입니다.

## 🧭 4. 단계별 학습 과정

본 서비스는 학습자가 앞 단계에서 선택한 색과 기록을 다음 단계에서도 활용하는 **6단계 연속 학습 구조**로 설계되었습니다.

| 단계 | 학습 화면 | 핵심 활동 | 학습 결과 |
| --- | --- | --- | --- |
| STEP 01 🎯 | 내 브랜드 | 활용 대상과 분야를 정하고 색·톤 선택 | 활용 맥락과 초기 컬러 후보 |
| STEP 02 🔎 | 내 색 이해하기 | 색의 이름·특성 관찰 및 톤 비교 | 색채 특성 이해와 비교 기록 |
| STEP 03 ⚖️ | 색 비교하기 | 배경·글자·도형의 대비 효과 실습 | 색의 대비 효과 이해 |
| STEP 04 🎚️ | 내 브랜드 팔레트 만들기 | 색의 역할과 사용 비율 조절 | 컬러 팔레트와 사용 비율 |
| STEP 05 🖼️ | 적용과 점검 | SVG 목업 적용 및 활용 위치 검토 | 브랜드 적용 및 점검 기록 |
| STEP 06 📄 | 컬러플랜 계획서 | 학습 결과 확인·편집·저장 | 브랜드 컬러 계획서 |

### STEP 01. 🎯 내 브랜드

**학습 활동:** 내 아이디어에 어울리는 색을 탐색합니다.

- 색을 사용할 대상과 활용 분야 선택
- 색상과 톤 탐색
- 3~5개의 컬러 후보 선택
- 색의 역할에 따른 초기 색채계획 구성

**학습 결과:** 활용 대상과 초기 컬러 후보

### STEP 02. 🔎 내 색 이해하기

**학습 활동:** 자신이 선택한 색의 특성을 살펴봅니다.

- 기본색명과 계통색명 확인
- 색상과 톤에 따른 이미지 형용사 탐색
- 밝기와 유사한 톤 비교
- 브랜드 이미지에 어울리는 색 검토

**학습 결과:** 색채 특성에 대한 이해와 비교 결과

### STEP 03. ⚖️ 색 비교하기

**학습 활동:** 색의 대비 효과를 직접 실험합니다.

- 배경과 글자의 색상 조합 비교
- 도형과 주변 배경색에 따른 시각적 차이 확인
- 대비 변화 및 가독성 관찰
- 비교 기준을 저장하고 조합 비교

**학습 결과:** 색의 대비 효과에 대한 이해

### STEP 04. 🎚️ 내 브랜드 팔레트 만들기

**학습 활동:** 선택한 색의 역할과 사용 비율을 결정합니다.

- 주조색·보조색·강조색의 역할 이해
- 슬라이더를 이용한 색상 비율 조절
- 비율 변화에 따른 팔레트 확인
- 브랜드 적용 미리보기

**학습 결과:** 색의 역할과 사용 비율이 포함된 컬러 팔레트

### STEP 05. 🖼️ 적용과 점검

**학습 활동:** 구성한 팔레트를 브랜드에 적용하고 결과를 검토합니다.

- 선택한 활용 분야의 SVG 목업 확인
- 팔레트가 적용된 브랜드 이미지 관찰
- 의도한 이미지가 표현되었는지 자기 점검
- 색별 활용 위치와 활용 이유 기록

**학습 결과:** 브랜드 컬러 적용 방향과 점검 기록

### STEP 06. 📄 컬러플랜 계획서

**학습 활동:** 이전 단계에서 만든 결과를 하나의 계획서로 정리합니다.

- 브랜드 정보와 선택한 컬러 확인
- 컬러 팔레트와 사용 비율 확인
- 색채 특성과 선택 이유 정리
- 계획서 내용 검토 및 수정
- PDF 형식의 계획서 저장

**학습 결과:** 브랜드 컬러 계획서 초안

## 🚀 6. 웹앱 이용 방법

### 🌐 웹앱 실행

**[My Color Plan 바로가기](https://my-colorplan.vercel.app/)**

별도의 프로그램 설치나 회원가입 없이 웹브라우저에서 사용할 수 있습니다.

### 📝 기본 이용 순서

1. 웹앱에 접속해 **실습 시작하기**를 선택합니다.
2. 색을 사용할 대상과 활용 분야를 선택합니다.
3. 원하는 색 3~5개와 톤을 선택합니다.
4. **더 이상 선택 안함**을 눌러 색 선택을 마무리합니다.
5. 색채계획 영역에서 주조·보조·강조 역할에 색을 배정합니다.
6. 단계별 색채 학습과 대비 실습을 진행합니다.
7. 팔레트 비율을 조절하고 브랜드 적용 결과를 확인합니다.
8. 최종 계획서를 검토하고 PDF로 저장합니다.

> 💡 이전 단계로 돌아가 색이나 비율을 수정할 수 있습니다. 작업 내용은 사용 중인 브라우저에 자동 저장됩니다.

## 🌱 8. 교육적 특징

### 🙋 8.1 학습자 중심의 색채 탐색

미리 정해진 색 조합을 단순히 추천받는 방식이 아니라 학습자가 자신의 목적에 맞는 컬러를 직접 선택합니다.

### 👀 8.2 이론과 실습의 연결

색채명, 톤, 대비, 배색 비율 등의 개념을 실제 조작 활동과 연결하여 시각적 변화를 확인할 수 있도록 설계했습니다.

### 🔗 8.3 단계 간 학습 데이터 연계

학습자가 처음 선택한 색과 브랜드 정보가 이후의 비교 실습, 팔레트 구성, 브랜드 적용 및 계획서에 연결됩니다.

각각의 학습 활동이 독립적인 체험에 머무르지 않고 하나의 컬러디자인 설계 과정으로 이어집니다.

### 🧠 8.4 학습자의 판단과 수정 과정 존중

웹앱은 특정 색이나 조합을 하나의 정답으로 평가하지 않습니다.

학습자가 여러 색채 표현을 직접 비교하고 자신의 목적에 맞는 조합을 선택하도록 지원합니다.

### 🧰 8.5 실제 활용을 고려한 결과물

학습 결과를 단순한 색채 지식 확인으로 끝내지 않고 실제 활용을 고려한 브랜드 컬러 계획서 초안으로 연결합니다.

| 색채 데이터 | 프로젝트 내부에 정의된 색상·톤 및 색채명 데이터 |
| 브랜드 시각화 | SVG 기반 목업 템플릿 |
| 계획서 생성 | 템플릿 기반 데이터 구성 |
| 데이터 관리 | 브라우저 기반 저장 및 파일 내보내기 |

본 MVP는 별도의 회원가입·로그인이나 서비스 데이터베이스 없이 핵심 학습 기능을 사용할 수 있도록 구성했습니다.

생성형 AI API를 이용한 실시간 컬러 코칭 기능은 현재 버전에 포함하지 않았습니다.

## 🤝 10. AI 활용 및 개발 과정

본 프로젝트는 **AI를 활용한 바이브코딩 방식**으로 제작한 웹 기반 교육콘텐츠입니다.

색채 교육의 학습 목표와 콘텐츠 구조를 바탕으로 단계별 학습 활동과 사용자 경험을 설계하고, AI를 개발 및 개선 과정의 협업 도구로 활용했습니다.

개발 과정에서는 다음 사항을 중점적으로 고려했습니다.

1. 색채 비전공자도 이해할 수 있는 교육콘텐츠 구성
2. 이론 학습과 직접 조작하는 실습 활동의 연결
3. 앞 단계의 학습 데이터가 다음 단계에 이어지는 UX 설계
4. 색채 데이터와 시각적 미리보기를 활용한 학습 지원
5. 사용자가 자신의 학습 결과를 계획서로 완성할 수 있는 구조 구현

특히 AI를 학습자의 컬러 선택을 대신 판단하는 도구가 아니라 **교육콘텐츠의 기획·설계·개발을 지원하는 협업 도구**로 활용했습니다.

현재 MVP는 사전 정의된 교육 데이터와 인터랙티브 실습을 결합하여 학습자가 스스로 색을 탐색하고 판단하도록 설계했습니다.

## 📚 11. 색채 데이터 및 콘텐츠

본 프로젝트는 색채 교육에 필요한 데이터를 프로젝트 내부에서 관리하도록 설계되었습니다.

주요 데이터는 다음과 같습니다.

- 기본 색상 및 기준 HEX 코드
- 색의 톤과 밝기에 관한 데이터
- 기본색명과 계통색명
- 색채 이미지 형용사
- 팔레트 역할 및 비율 처리 규칙
- 브랜드 활용 분야별 SVG 템플릿

### ⚠️ 색채 데이터 이용 안내

색상과 톤의 HEX 값은 학습과 탐색을 돕기 위한 시각적 참고값입니다.

디스플레이와 사용 환경에 따라 색이 다르게 보일 수 있으며, 앱에서 제공하는 모든 색상값이 공식 표준 측색값이나 실제 인쇄 결과와 정확하게 일치하는 것은 아닙니다.

또한 색에서 느끼는 이미지는 사람, 문화, 활용 분야 및 사용 맥락에 따라 달라질 수 있습니다.

색채 이미지 형용사와 시각적 예시는 학습자가 색을 비교하고 생각하는 데 도움을 주는 자료입니다.

## 🧪 12. MVP 구현 범위 및 한계

### ✅ MVP 핵심 구현 범위

- 6단계 색채 학습 활동
- 색상 및 톤 탐색
- 색채 특성 관찰 및 대비 실습
- 컬러 팔레트 비율 조절
- SVG 기반 브랜드 적용 목업
- 학습 결과 점검
- 템플릿 기반 브랜드 컬러 계획서
- PDF 저장 및 데이터 내보내기

### ⚠️ 현재 버전의 한계

- 생성형 AI 기반 맞춤형 색채 진단 및 실시간 코칭은 제공하지 않습니다.
- 브랜드 목업은 실제 촬영 이미지가 아닌 사전 제작된 SVG 템플릿을 활용합니다.
- 색채 이미지의 적합성은 학습자의 판단과 실습 활동을 중심으로 검토합니다.
- 전문 컬러 매니지먼트 소프트웨어 수준의 색상 정확도나 인쇄 결과를 보장하지 않습니다.
- 브랜드 컬러 계획서는 실제 디자인 제작을 위한 최종 명세서가 아닌 기초 계획입니다.
