## 🌐 웹앱 체험하기

**[My Color Plan 바로가기](https://my-colorplan.vercel.app/)**

별도의 회원가입이나 프로그램 설치 없이 웹브라우저에서 이용할 수 있습니다.

학습자는 6단계의 색채 실습을 진행하며 자신만의 컬러 팔레트를 구성하고, 최종 결과물을 브랜드 컬러 계획서(PDF)로 저장할 수 있습니다.

## 학습 결과물

본 웹앱의 최종 산출물은 **브랜드 컬러 계획서**입니다.

학습자는 자신이 선택한 색채 정보와 학습 과정에서 작성한 내용을 바탕으로 다음 항목을 정리할 수 있습니다.

- 브랜드 또는 컬러 활용 대상
- 선택한 색의 이름과 HEX 코드
- 주조색·보조색·강조색의 역할과 사용 비율
- 색채의 특성과 선택 이유
- 브랜드 컬러 적용 미리보기

완성된 계획서는 PDF로 저장하여 이후 컬러디자인을 구체화하거나 다른 사람과 공유하는 기초 자료로 활용할 수 있습니다.

본 계획서는 전문적인 컬러디자인 최종 명세서가 아닌, 학습자가 자신의 색채 활용 방향을 정리한 초안입니다.

## AI 활용 및 개발 과정

본 프로젝트는 AI를 활용한 바이브코딩 방식으로 개발한 웹 기반 교육콘텐츠입니다.

색채 교육의 학습 목표와 콘텐츠 구조를 바탕으로 단계별 학습 활동과 사용자 경험을 설계하고, AI의 도움을 받아 웹앱을 구현하고 개선했습니다.

개발 과정에서는 다음 사항을 중점적으로 고려했습니다.

1. 색채 비전공자도 이해할 수 있는 학습 콘텐츠 구성
2. 이론 학습과 직접 조작하는 실습 활동의 연결
3. 앞 단계의 학습 데이터가 다음 단계에 이어지는 사용자 경험 설계
4. 색채 교육 데이터와 시각적 미리보기를 활용한 학습 지원
5. 사용자가 자신의 학습 결과를 계획서로 완성할 수 있는 구조 구현

특히 AI를 학습자의 컬러 선택을 대신 판단하는 도구가 아니라, **교육콘텐츠의 기획·설계·개발을 지원하는 협업 도구**로 활용했습니다.

최종 웹앱은 사전 정의된 색채 데이터와 규칙을 활용해 학습자가 스스로 탐색하고 판단하도록 설계했습니다.

## 향후 개선 계획

본 프로젝트는 핵심 학습 기능을 우선 구현한 MVP 버전입니다.

향후 사용자 테스트와 피드백을 바탕으로 다음 사항을 검토할 예정입니다.

- 팔레트 비율 조절 기능의 키보드 접근성 개선
- 모바일 및 다양한 화면 환경에서의 사용자 경험 개선
- 색채 이미지와 상징에 관한 학습 콘텐츠 확장
- 브랜드 적용 예시와 목업 다양화
- 학습자 피드백을 반영한 단계별 안내 개선

현재 구현된 핵심 기능을 유지하면서 학습 편의성과 접근성을 점진적으로 개선할 계획입니다.
